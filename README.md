One original funny line for make.fun's "Make the Judge Laugh in One Line": a
single line of at most 200 characters, built to be read aloud in one breath —
about asking a GPS for the quickest route to happiness and waiting three years
for it to finish recalculating.

## How to run

```sh
node main.ts   # writes /output/entry.txt
```

`main.ts` uses only the Node standard library, validates the line (one line,
1–200 characters, not only whitespace), and writes the same bytes on every run.
